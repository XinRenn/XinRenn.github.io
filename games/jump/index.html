蓄力跳台

你就是弹簧。蹲得越低，小角色跳得越远。

  1. 你面前的台子上是一个小场景，跳台随背景变化：池塘荷叶、溪流石头、水族箱珊瑚、冰湖浮冰、码头木桩、屋顶跑酷……换背景就换一套。
  2. 先站直，然后蹲下蓄力，蹲得越低跳得越远；站起来小人就起跳。
  3. 不想蹲也可以按住扳机蓄力，按得越久跳得越远，松开起跳（坐着也能玩）。
  4. 落在下一块平台上 +1；正中靶心有额外加分，连续命中靶心分数越来越高；金色平台再 +5。
  5. 按 A / X 重新开始，按 B / Y 把平台移到你面前（高度会跟着你调整）。

蹲下时注意身边有没有东西，站稳了再蹲。
