大力搬箱

关卡放在你面前的桌子上，伸手推着小人走，让小人把木箱推到黄色圆圈里。

  1. 关卡缩小放在你面前的桌子上，不用走动，站着坐着都行。桌上那个小人就是“你”。
  2. 伸手碰到小人（手柄前面的白色小球变黄、小人脚下的圈变黄），然后往哪边推，小人就往哪边走一格；一直推着，小人就一格一格往前走。
  3. 小人走进箱子，就把箱子往前推一格。箱子只能推、不能拉，推到墙角就拿不出来了。把所有箱子推到黄色圆圈上就过关。
  4. 也可以用摇杆走（方向按你面对的方向），或者用射线点小人旁边的格子。按 A / X 撤销一步，B / Y 把桌子移到面前。
  5. 面板上有提示、重来、上一关/下一关、随机关卡、背景和 ✕ 退出。抬起左手还能看手腕地图。

墙和箱子都是虚拟的，身体可以穿过去。请先清出约 2.5×2.5 米的空地并设置好安全边界。
