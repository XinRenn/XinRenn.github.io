点方块 = 用镐敲一下 · 拖动转视角 · 敲碎脚下中间那块就往下掉

深井矿工样品

你站在一口矿井里，手里拿着镐，一直往下挖。头顶不停有石块掉下来，挖慢了就会被埋住。

  1. 两只手柄都是镐。挥动手柄砸方块（要用力挥，轻轻碰不算），每砸一下方块会裂开，砸够次数就碎了。
  2. 砸碎脚下正中间那块（镐头比手长，手不用碰到真的地板），整层就塌了，你往下掉一层（0.6 米），四周堆的碎石也会塌掉一半。越往下石头越硬。
  3. 头顶会不停掉石块，红圈提示它要落在哪里。四周的石堆可以一下砸掉；正对你头顶的那块要么在空中砸碎，要么歪头躲开，不然扣一颗心。四周堆满了你就被埋住了。石块掉得越来越快，所以要不停往下挖。
  4. 闪光的宝石矿和金矿加分，红色的炸药箱砸一下会把周围一圈都炸开。
  5. 得分 = 深度 + 矿石。按 A / X 重新开始，B / Y 把矿井对准你脚下。

这是样品，先试试手感。挥镐前确认四周没有人和东西，抓紧手柄、戴好腕带。
