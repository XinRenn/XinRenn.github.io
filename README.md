# 口袋 VR 游乐场

在 Meta Quest 浏览器里玩的体感小游戏合集，用 WebXR + three.js 写成，不需要安装任何东西。

网址：https://xinrenn.github.io/

## 游戏

| # | 名字 | 玩法 | 状态 |
|---|------|------|------|
| 01 | 雷区漫步 | 雷区铺在地板上，走过去踩格子翻开 | 可以玩 |
| 02 | 蓄力跳台 | 面前台子上的小角色往你面对的方向跳；按住扳机蹲下蓄力（可反悔），松开起跳 | 可以玩 |
| 03 | 空中连线 | 用手在空中把 3 个以上上下左右相邻的同色圆点连成线消掉；闯关（冰块、石头）/无尽/60 秒 | 可以玩 |
| 04 | 方塔消消 | 绕着方块塔抽露出来的方块，7 格槽里三个一样就消除 | 可以玩 |
| 05 | 大力搬箱 | 关卡放在面前的桌子上，伸手推小人，小人推箱子（也可摇杆/射线） | 可以玩 |
| 06 | 深井矿工 | 站着挥镐挖空四周一圈就往下掉一层，落石越堆越高，别被埋住 | 样品 |
| 07 | 星石三连 | 交换相邻两颗星石凑 3 连消除，特殊星石、闯关（离线机器人测过每关能过）/无尽 | 可以玩 |

## 目录

```
index.html          大厅
games/<游戏>/       每个游戏一个文件夹（index.html + main.js）
shared/             公共代码：VR 设置、3D 按钮、音效、二维几何、退出按钮、手腕地图、把场地放进安全边界
shared/env/         背景场景：草地森林、海底世界、冬日雪地、秋日港口、峡湾、瀑布、日本街头、雨中伦敦
.nojekyll           让 GitHub Pages 原样发布所有文件
```

## 在电脑上调试

不能直接双击打开 html（浏览器会拦截模块加载），需要起一个本地服务器：

```bash
cd 仓库目录
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。没有头显时，雷区漫步可以用鼠标玩：左键踩格子、右键插旗、拖动转视角。
