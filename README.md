# 口袋 VR 游乐场

在 Meta Quest 浏览器里玩的体感小游戏合集，用 WebXR + three.js 写成，不需要安装任何东西。

网址：https://xinrenn.github.io/

## 游戏

| # | 名字 | 玩法 | 状态 |
|---|------|------|------|
| 01 | 雷区漫步 | 雷区铺在地板上，走过去踩格子翻开 | 可以玩 |
| 02 | 蓄力跳台 | 蹲下蓄力，站起来起跳 | 制作中 |
| 03 | 空中连线 | 在空中画线连起相同图案 | 制作中 |
| 04 | 方塔消消 | 绕着方块塔抽方块，三个一样就消除 | 制作中 |
| 05 | 大力搬箱 | 在地板上推箱子到目标点 | 制作中 |

## 目录

```
index.html          大厅
games/<游戏>/       每个游戏一个文件夹（index.html + main.js）
shared/             公共代码：VR 设置、3D 按钮、音效
.nojekyll           让 GitHub Pages 原样发布所有文件
```

## 在电脑上调试

不能直接双击打开 html（浏览器会拦截模块加载），需要起一个本地服务器：

```bash
cd 仓库目录
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。没有头显时，雷区漫步可以用鼠标玩：左键踩格子、右键插旗、拖动转视角。
